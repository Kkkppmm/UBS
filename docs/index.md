# USBForge Help

Welcome to **USBForge** - create bootable ISOs, write them to USB, and boot into a USB Lab for testing and docs (not just install).

## Topics

- **getting-started.md** - First steps
- **create-iso.md** - Building the ISO
- **write-usb.md** - Writing the ISO to a stick
- **live-lab.md** - What the Live session offers
- **usb-testing.md** - How USB tests work
- **safety.md** - Avoid wiping the wrong disk

## Two programs

1. **USBForge Builder** (host) - build & write media  
2. **USBForge Live** (boot session) - USB Lab GUI after you boot the ISO/USB

Pick a topic button above, or open these files in `docs/`.
